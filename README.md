- **[AI Safety & Guardrails](https://github.com/ThisisHappyEL/ecommerce-ai-guardrails)** - пайплайн для LLM-ассистента с изоляцией контекста и защитой от Prompt Injection / галлюцинаций. *(Python 3.12, OpenRouter API)*
